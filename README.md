# saenai255/tap

Homebrew casks by [saenai255](https://github.com/saenai255).

```bash
brew install --cask saenai255/tap/openbar
brew install --cask saenai255/tap/macphin
```

| Cask | Description |
| --- | --- |
| [openbar](Casks/openbar.rb) | [OpenBar](https://github.com/saenai255/openbar), a Windows-style taskbar for macOS |
| [macphin](Casks/macphin.rb) | [Macphin](https://github.com/saenai255/macphin), a Dolphin-style file manager for macOS |
